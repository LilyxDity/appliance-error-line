The funniest honest error message a washing machine could show:

> ERROR E04: 1 sock in, 0 socks out. This is not a fault. This is the job.

Every washing machine owner has lost a sock to the wash. The laugh comes from
the truth of the fault, not a pun bolted on — the machine is not
malfunctioning, it is confessing. The error-code format and the flat denial
make it read like a real display message, as if the machine wrote it without
meaning to be funny.

## Run it

```sh
node main.ts
```

This writes the single line (72 characters, one line, no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
